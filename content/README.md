# content — 展示で使うコンテンツ

D34により展示は完全オフラインで動くため、**来場者が目にするセリフはすべてここに入っている。**当日にAIを呼ばない以上、このディレクトリの中身が展示の質そのものになる。

| ファイル | 内容 | 使う場所 |
|---|---|---|
| [dialogues/greeting.json](./dialogues/greeting.json) | 検出直後の短い一言 | セクション2・4 |
| [dialogues/moisture.json](./dialogues/moisture.json) | 土壌水分に応じたセリフ | セクション4 |
| [dialogues/timeline.json](./dialogues/timeline.json) | 時系列パネル用のセリフ | セクション3 |

## セリフの規則

すべてのセリフは以下を満たす。`server` の `npm run check:dialogues` で機械的に検証できる。

| 規則 | 根拠 |
|---|---|
| 一人称代名詞（ぼく・わたし・おれ 等）を使わない | D31 |
| 40字以内 | 設計 |
| 計測値を言わない（%・℃・ルクス等） | 原則2 |
| 絵文字・顔文字を使わない | 設計 |
| ユーザーを責めない | D30 |
| ユーザーに指示しない | 設計 |

## 植物種への依存

| ファイル | 種依存 |
|---|---|
| `greeting.json` | しない |
| `moisture.json` | **しない。**水分だけで決まるため |
| `timeline.json` | **する。**現在はミニひまわり前提。種が決まったら差し替える |

展示に使う植物の種類は未確定（D17-a）。`timeline.json` だけが影響を受ける。

## 選び方

同じ帯域の中からランダムに1本選ぶ。ただし**直前に出したものは除外する**。来場者の滞在は数分なので、この程度で繰り返しは避けられる（D34）。

## 増やしたくなったら

`server/src/diagnosis/` に Claude を呼ぶ実装が残してある。API キーを設定すれば、条件を変えて大量に生成できる。生成したものは `npm run check:dialogues` でふるいに掛けてから、人が選んでここに入れる。
