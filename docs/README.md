## plavo とは

カメラを植物に向けると、実物の植物から吹き出しが出て、その植物が自分の言葉で状態を伝えるアプリ。最終的な目標は、ユーザーがその植物の死に人の死と同等に感情移入して泣くこと。

詳細は [requirements/README.md](./requirements/) を参照。

## 進め方

要件を確定 → 技術選定 → 設計 → 実装、の順に進める。

**現在地: 設計に着手。アーキテクチャとドメインモデルが完了。**

技術スタックは iOSネイティブ（Swift + SwiftUI + ARKit + Vision）で暫定確定。

## ドキュメントの作法

- ファイル冒頭に、そのファイルが何かを示すタイトルを書く
- `docs/` 内にディレクトリを作ったら、直下に `README.md` を置いて目次にする
- 作業したら随時 `docs/devlog/yyyymmdd.md` にログを追記する（実装に限らない）
- ファイル名は ASCII のケバブケース、本文とタイトルは日本語

詳細は [CLAUDE.md](../CLAUDE.md) を参照。
