### 2. 育成者が欲しがるデータのリサーチ

D23でユーザーから「植物育成者が嬉しがるデータをリサーチして項目に入れてみて」という指示があり、Web検索で調査した。

結果、4つの指標が繰り返し挙がった。**いずれもガジェットの5項目から計算で導出でき、追加センサーは不要**。

| 指標 | 内容 |
|---|---|
| DLI（積算光量） | 園芸で光を語る唯一の標準指標。照度ではなく1日に浴びた光の総量 |
| GDD（積算温度） | 生育の進行度。ひまわりは基準温度6.7℃、**開花に約958 GDD** |
| VPD（飽差） | 気温＋湿度から計算。湿度単体より蒸散をよく表す |
| 次の水やり予測 | 既存の水やりアプリ最大の不満（固定間隔による根腐れ）への構造的な回答 |

**GDDによる開花予測がひまわりで成立する**のが大きな発見だった。D17でミニひまわりを選んだ判断の思わぬ副産物で、植物自身が「あと12日で咲くよ」と言えるようになる。

### 3. 診断項目の設計方針の転換

リサーチ結果を診断の出力項目に追加する提案をしたところ、ユーザーから重要な指摘を受けた。

> この情報に必要なのは、元データです。何かのデータを元に推測できるデータは、この項目には必要ないです。
> 開花予測日などは、情報ではなくコミュニケーションの中で情報を提供します。

**これで2つの原則が確立した。**

1. **再計算できるものは保存しない** — 導出値を保存すると、後で計算式を直したときに過去データと矛盾する
2. **情報を情報として出さない** — 数値を表示した瞬間に農業管理アプリになる。植物が言うからこのアプリである

後者は D2（キャラを作らない）、D5（声を当てない）と同じ論理の延長であり、このプロダクトを貫く原則だと分かった。

ただし例外として、**AIが見たことは保存する**（D23-a）。センサー値や計算値は何度計算しても同じ答えになるが、AIの観測はその瞬間にしか存在せず再現できない。保存しないと、3ヶ月後の再診断で当時のセリフと食い違い、その日の記憶が書き換わってしまう。

## 気づいたこと

**技術的制約が体験に変換される構造が、このプロダクトには繰り返し現れる。**

| 制約 | 体験への変換 |
|---|---|
| 動画生成に数分かかる | 植物が眠って夢を見ている時間 |
| 画像認識は水やりを見逃す | 自信なさげに「気のせいかな」と言う性格 |
| 診断に5〜15秒かかる | 必ず喋るとは限らない沈黙 |
| 通信が切れると診断できない | 少し眠そうにしている様子 |
| 実物の植物は動かせない | 夢の中でだけ動く |

制約を隠すのではなく、植物の性質として引き受けている。これは偶然ではなく、原則1（実物を主役から降ろさない）と原則3（失敗をユーザーのせいにしない）から必然的に導かれている。

## 追記 — L-8 の解決（D30）

要件の残課題のうち最優先だった L-8（死因の判定と、追悼ムービーの語り口の出し分け）を解決した。

### 問いの立て方が誤っていた

当初これを「死因に応じて語り口を分ける」問題として記録していたが、正しい問いは「**追悼の場で死因を語る必要があるのか**」だった。

D18-a の目標は「泣くこと」だが、糾弾されて流す涙は悲しみではなく罪悪感で、別物である。一方で「寿命でした」と嘘をつけば、リアリティ追求の方針に反する。人間の葬式は死因を糾弾しないが嘘もつかない——**触れない、という第三の選択肢**があった。

### ユーザーからの上積み

「触れない」という案に対し、ユーザーから重要な追加があった。

> 通常明示することで、明示されていなかった時にユーザーに察せさせる手法にも賛成です

天寿のときだけ「役目を果たした」「種を残したよ」と明示し、そうでないときはその言葉が**出てこない**。ユーザーは、あるはずの言葉がないことで自分で気づく。

**アプリは一度も責めていないのに、ユーザーは理解する。**しかも自分で気づいた理解なので、外から言われるより深く刺さり、角が立たない。文学の省略法にあたる。

制約として、この手法は1株目では成立しない（比較対象がないため不在に気づけない）。ただし主目的である「責めない」は1株目から満たされる。

### 3層に分けた

| 層 | 内容 |
|---|---|
| 第1層 予防 | 危険域が続いたらセリフの切迫感を上げる。**死んでから語り方を工夫するより死なせないほうがいい** |
| 第2層 追悼 | 死因に触れない。天寿のときだけ明示。トーンのみ判定に応じて変える |
| 第3層 振り返り | 追悼とは別導線。事実を正直に書くが断定せず、観察頻度には言及しない |

**追悼と反省を同じ画面に置かない**のが鍵。葬式と反省会は別の場所でやる。
