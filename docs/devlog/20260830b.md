## 2. C-1 を解決し、バグが1つ見つかった（D38）

長く未確定だった「カメラを反転させる」の意味が、**①端末を上下逆さまにする**ことだと判明した。

**この確認によって実装のバグが露見した。**Vision へ渡す画像の向きを `.right`（縦持ち）で決め打ちしており、**端末を上下逆さまにすると検出が働かない**状態だった。ARKit が渡す画像はカメラの物理的な向きのままなので、画面の向きに合わせて回転の指定を変える必要がある。

画面の向きから導出するよう修正し、上下反転を対応向きに追加した。**横向きは対応しない**（吹き出しのレイアウトが縦持ち前提のため）。

**要件の曖昧さを放置していた分、バグも放置されていた。**3回聞いて答えが得られず、そのまま実装を進めていたが、答えが出た瞬間に既存のバグが1つ見つかった。

## 4. Git履歴から node_modules を除去した

過去のコミットに `server/node_modules` の3,316ファイルが入っており、リポジトリの大半を占めていた。

| 項目 | 前 | 後 |
|---|---|---|
| `.git` のサイズ | 26MB | **420KB** |
| 履歴中の参照 | 6,537件 | 0件 |
| コミット数 | 23件 | 23件（すべて保持） |

`git filter-repo` で除去した。**バックアップを `/tmp/plavo-backup-20260830-045526.bundle` に取ってある。**

**force push は環境の安全機構にブロックされたため、未実行。**ユーザーの手で実行してもらう必要がある。
