# 2026-09-29 開発ログ

## 紹介動画を Remotion で作る

### 依頼

> Remotionを使ってこのサービスの紹介動画を作りたいです。サービスの概要などではなく、実際の画面の操作感を伝える動画です。

縦型モニターに映すので縦長、尺は30秒程度、BGM はなし。

### やったこと

- **`video/` に Remotion のプロジェクトを作った。**1080×1920・30fps・約30.7秒。端末の枠に録画をはめ、上に章（マイプラント／日記／トーク／プロフィール）の切り替えと一言、最初と最後に「plavo／植物の気持ち翻訳アプリ」
- **操作は UIテストで台本にした**（`ios/PlavoApp/UITests/DemoTourTests.swift`・`project.yml` に `PlavoAppUITests` を足した）。ひまりを開く → 育成のグラフ → ギャラリー → 日記を友達・みんなへめくる → スタンプ 🌸 → ダブルタップで ❤️ → わが家のチャットで送る → プロフィールで2本指
- **`npm run record`**（`video/scripts/record.mjs`）でビルド・録画・台本・30fps への変換までを1回で流す
- **切り出しは `video/src/cuts.ts`** に、録画の秒で書いた。台本は操作のたびに待つので録画は約84秒あり、画面が止まっている間で切って詰めた
- アプリに**起動引数 `-showTouches YES`** を足した（`TouchIndicator.swift`）。指の位置に丸を出す

### 詰まった点

**指の跡が押した瞬間と合わなかった。**シミュレータの録画には指が映らないので、はじめは台本から押した時刻と位置を書き出し、Remotion の側で丸を重ねるつもりだった。ところが録画を見ると、操作が記録より早く映っていた。ずれは一定でなく、始めは約0.4秒、30秒あたりで約2秒。**simctl の録画の時刻が壁時計から少しずつずれている**（生の録画でも同じだったので、30fps への変換のせいではない）。時刻で合わせるのをやめ、**アプリ自身が指の位置に丸を描く**形に変えた。丸も画面と同じ録画に入るので、ずれようがない。

**プロフィールでピンチしたらトークへ移った。**画面全体に向けてピンチすると、片方の指がタブバーに乗り、寄せる動きでタブの選択を引っ張っていた（タブバーはなぞった指に付いてくる）。中央の写真1枚の上でつまむようにした。

**ピンチで列が増えすぎた。**XCUITest のピンチは勢いが付き、3列から10列近くまで進んだ。戻すピンチも狙った写真に当たらなかった。控えめにゆっくり1回だけつまむ形にした（3列 → 7列ほど）。

### 判断したこと

- **カメラ（AR）は入れていない。**ARKit はシミュレータで動かない。入れるなら実機の画面収録を切り出しの1つとして足す
- 文字は macOS の丸ゴシック（ヒラギノ丸ゴ）。描画は手元の Chrome で行うので、Web フォントを読み込まずに済む
- アクセントはアプリと同じシステムの緑。章の切り替えは、アプリの切り替えの部品（D55）に倣って塊が横へ移る

### 確かめたこと

- `npm run render` で `video/out/plavo-tour.mp4`（1080×1920・30fps・30.7秒）が書き出せる
- 書き出した動画をコマ送りで見て、つなぎ目に飛びがないこと、指の丸・スタンプ・❤️・キーボードの入力が映っていること
