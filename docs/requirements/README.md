## plavo とは

カメラを植物に向けると、**実物の植物から吹き出しが出て、その植物が自分の言葉で状態を伝える**アプリ。キャラクターは作らず、主役は目の前の実物の植物のまま。

最終的な目標は、ユーザーがその植物の死に、人の死と同等に感情移入して泣くこと。植物管理ツールではなく、愛着と喪失を扱う作品である。

## 貫く3つの原則

設計判断はすべてここに帰着する。迷ったらここに戻る。

1. **実物を主役から降ろさない** — キャラを作らない、声を当てない、AI生成の絵を使わない
2. **情報を情報として出さない** — 数値を表示せず、必ず植物の言葉に翻訳する
3. **失敗をユーザーのせいにしない** — 未検出もオフラインも、エラーではなく植物の様子として描く
