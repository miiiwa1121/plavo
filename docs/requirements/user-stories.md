# ユーザーストーリー

plavo の利用シナリオを、**時間軸に沿った物語**として記述する。このプロダクトの価値は単発の機能ではなく数ヶ月の積み重ねに宿るため、機能単位ではなく経過単位で書く。

最終更新: 2026-08-28

## 1. 想定するユーザー

| 項目 | 内容 |
|---|---|
| 誰 | 室内でミニひまわりを育てはじめた人 |
| 経験 | 植物を育てるのは初めて、または過去に枯らした経験がある |
| 動機 | 育てたいが、水やりの量やタイミングに自信がない |
| 恐れ | 「また枯らしてしまうかもしれない」 |

**この恐れが出発点である。**植物を枯らす人は、愛情がないのではなく、植物が何も言ってくれないから分からない。plavo はそこに言葉を与える。

## 2. 時間軸のストーリー

### 初日 — 出会い

> アプリを開くと、いきなりカメラが立ち上がった。説明もログインもない。
> 買ってきたばかりの鉢に向けると、ふわりと吹き出しが出た。
>
> 「はにゃ？？？」
>
> 少し間があって、言葉が続いた。
>
> 「はじめまして。ぼくに名前をつけてくれる？」

名前を入力する。それだけで登録が終わる。フォームは一つも出てこない。

**満たす機能**: F-01 / F-02 / F-03 / F-06

### 3日目 — 最初の異変

> 帰宅して、いつものようにカメラを向ける。
>
> 「なんだか土が乾いてる気がするんだけど…気のせいかな」
>
> 半信半疑で土を触ってみると、確かに乾いていた。水をやる。

**ここで確信度が効いている。**AIは断定していない。もし外れていても「気のせいかな」で済む。当たっていたときだけ、ユーザーは驚く。

**満たす機能**: F-04 / F-05（確信度のトーン反映）

### 3日目・夜 — 手応え

> 水をやってから数時間後、もう一度カメラを向けた。
>
> 「ありがとう、生き返った。さっきまで、ちょっと苦しかったんだ」

**お世話ボタンは押していない。**植物が自分で気づいた。ここが「申告制を採らない」（D7）ことの報酬である。

**満たす機能**: F-04（前回との差分）/ F-07

### 2週間目 — 関係の変化

> 「おはよう」
>
> 今まで言わなかったことを言うようになった。
> いつのまにか、名前を呼ばれるようにもなっている。

親密度がセリフの層を深くしている（D12）。ゲージは表示されない。ユーザーは「最近よく喋るようになった」と体感するだけ。

**満たす機能**: G-06（今回は実装しない）

### 1ヶ月目 — 予告

> 「あと12日で咲くよ」
>
> なぜそんなことが分かるのか、アプリは説明しない。
> 植物が知っているから言っている、という顔をしている。

裏では積算温度（GDD）から開花日を予測している。だがその数値は画面のどこにも出ない（原則2）。

**満たす機能**: F-04（導出指標をセリフに翻訳）

### 45日目 — 開花

> 本当に咲いた。予告は2日ずれていた。
> その日の日記に、写真を貼って、一行だけ書いた。

**満たす機能**: F-09

### 90日目 — 終わり

> 最近、言葉が少ない。
> 「……」だけの日が続いている。
>
> ある朝、吹き出しが出なくなった。
> 代わりに、3分の動画が用意されていた。

出会った日の小さな芽から、咲いた日の写真、書いた日記、交わした言葉。

**満たす機能**: F-13

**未解決（L-8）**: このとき「寿命を全うした」のか「枯らしてしまった」のかで、語り口を変える必要がある。世話を怠って死なせた人に同じ動画を見せるのは、追悼ではなく糾弾になる。

## 3. 短いストーリー一覧

| # | として | したい | なぜなら |
|---|---|---|---|
| US-01 | 育てはじめた人 | 説明を読まずに使いはじめたい | 説明が要るなら、植物の気持ちが分かるとは言えないから |
| US-02 | 水やりに自信がない人 | 今日水をやるべきか知りたい | 一定間隔でやると根腐れさせてしまうから |
| US-03 | 育てている人 | 世話をした結果を知りたい | やったことが届いているか分からないと続かないから |
| US-04 | 育てている人 | 記録を残したい | 後で振り返りたいから |
| US-05 | 育てている人 | いつ咲くか知りたい | 楽しみが具体的になるから |
| US-06 | 複数株を持つ人 | どの株か見分けてほしい | 記録が混ざると意味がなくなるから |
| US-07 | 出先にいる人 | 開いても気まずくないでほしい | 植物がいない場所で「見つかりません」と怒られたくないから |
| US-08 | 通信が不安定な場所にいる人 | それでも植物に会いたい | エラー画面は関係を断ち切るから |
| US-09 | 植物を失った人 | その子がいた時間を振り返りたい | 記録が消えたら、生きた証も消えるから |

## 4. 使わない場面

以下は明示的に設計対象としない。

| 場面 | 理由 |
|---|---|
| 屋外の庭木・花壇を診断する | D17。室内の鉢植えに限定 |
| 他人の植物を診断する | 個体同定と記録の前提が崩れる |
| 植物の売買や品種調査に使う | 図鑑機能はスコープ外 |
| 複数人で1株を管理する | 階層3（G-05）の家族シェアで扱う |
